DO FORMULÁRIO AO REGISTRO

Não basta parecer correto.

01 · SINTÁTICO

O formato está certo?

ana@ está incompleto. O sistema indica o campo e pede correção, sem gravar nada.

02 · SEMÂNTICO

O valor faz sentido?

Uma data futura pode ter formato válido, mas não serve como nascimento.

03 · NEGÓCIO

A regra permite?

Inscrições abertas e vaga disponível. Uma turma lotada não pode receber outro aluno.

04 · INTEGRIDADE

O registro é consistente?

Referências válidas e matrícula única. Se a operação falhar, as mudanças são desfeitas juntas.

DUAS IMPLEMENTAÇÕES, O MESMO CONCEITO

Confirmar tudo.
Ou não gravar nada.

Online: formulário → serviço JavaScript → transação IndexedDB → confirmação ou abort.

Python local: formulário → API → BEGIN IMMEDIATE → banco SQLite → COMMIT ou ROLLBACK.

A disputa pela última vaga é serializada entre abas da mesma origem na demonstração. Dispositivos diferentes têm bancos independentes. Em produção, use API autenticada e banco compartilhado.
