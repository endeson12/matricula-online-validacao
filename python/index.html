Matrícula online

Exemplo didático: sintático → semântico → negócio → integridade.

Use somente dados fictícios nesta demonstração local.

Nenhum dado enviado.

Pipeline de execução

  1. Formulário coleta e confere os campos.
  2. API repete as validações sintáticas e semânticas.
  3. BEGIN IMMEDIATE: bloqueia a escrita concorrente.
  4. Confere existência, duplicidade, inscrições abertas e vagas.
  5. Cadastra aluno, reduz vaga e grava matrícula na mesma transação.
  6. COMMIT → comprovante. Falha → ROLLBACK, sem gravação parcial.

Sem autenticação: demonstração acadêmica, não sistema de produção. SQLite bloqueia escritores no banco, não uma linha isolada.
